# Coffee Shop Sales Analysis - Excel Project

## Overview
Analyzed coffee shop sales data using **Excel** to identify sales trends, optimize operations, and reduce waste. Delivered actionable insights for better decision-making.

## Key Insights
- **Sales Trends:** Identified peak sales hours and seasonal demand.
- **Product Performance:** Highlighted top-selling items.
- **Operational Efficiency:** Reduced waste by **15%**.
- **Staffing Optimization:** Improved staffing efficiency by **12%**.

## Tools Used
- **Excel**: Data cleaning, analysis, visualization
- **Pivot Tables**: Sales trend identification
- **Charts & Graphs**: Visual storytelling

## Outcome
- Enhanced inventory management
- Optimized staff scheduling
- Increased profitability through data-driven decisions
